## About

I'm **Benjamin**, a full stack developer with an end to end mindset.

I like understanding a product beyond a single layer, from **Figma and data modeling** to **backend architecture, frontend development, delivery, cloud, and AI integration**.

Today, I build mainly with **React and Node.js**. I'm deliberately expanding toward **Java, Angular, cloud engineering, CI/CD, and agentic AI** to become the kind of engineer who can understand a system as a whole, adapt quickly, and build software that remains clear as it grows.

> **Software should be understandable before it is impressive.**

<br>

## How I Think

**01. Adaptability**  
Learn the problem first. Choose the right tools second. Keep evolving.

**02. Clarity**  
Readable code, explicit architecture, meaningful naming, and error handling that actually helps.

**03. Product Thinking**  
A technically correct solution is not enough. The product still has to make sense for the person using it.

**04. Ownership**  
From the first idea to deployment, monitoring, iteration, and maintenance.
